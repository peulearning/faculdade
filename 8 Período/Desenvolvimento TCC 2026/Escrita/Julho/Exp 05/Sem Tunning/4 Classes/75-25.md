## 4. Conclusões Científicas Finais (Para o seu Relatório)

O cruzamento desses dados revela uma lei de comportamento muito clara para o seu ecossistema de dados:

1. **O Fine-Tuning é obrigatório em Splits Maiores (75/25 e 80/20):** Repare que no split 75/25, quando você ativou o Fine-Tuning, a acurácia saltou de **88.65% para 92.91%**. Por que? Porque com mais dados disponíveis para treino, a rede precisa recalibrar os pesos da base para capturar os padrões visuais mais sutis e não confundir úlcera diabética com venosa.
    
2. **O paradoxo do Split Menor (70/30):** No 70/30, o Fine-Tuning atrapalhou (caiu para 91.72%), porque havia poucos dados e a base começou a sofrer overfitting. Congelar a base foi a melhor estratégia ali (92.90%).
    
3. **A Configuração Campeã Indiscutível:** O modelo **80/20 com Fine-Tuning** é a sua obra-prima. Ele atingiu 97.32% porque atingiu o "ponto de saturação ideal": dados suficientes no treino para justificar o ajuste fino da base, sem gerar overfitting na validação.
